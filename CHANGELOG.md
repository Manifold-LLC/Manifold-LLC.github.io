# Changelog

Notable changes to manifold-llc.com. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). This site does not use Semantic Versioning; launches are tagged by date (for example `launch-2026-11`).

## [Unreleased]

### Added
- Hand-built single page replacing the HTML5 UP "Solid State" template: `index.html`, `assets/css/site.css`, `assets/js/site.js`.
- Self-hosted fonts: Newsreader, IBM Plex Sans, IBM Plex Mono (SIL Open Font License), with license files in `assets/fonts/`.
- Wireframe manifold drawing generated by `scripts/surface.py`, used for the hero, logo mark, favicon and share image.
- Print-styled capability statement (`capability-statement.html`) and its one-page PDF.
- `404.html`, `robots.txt`, `sitemap.xml`, `.well-known/security.txt`, favicon set, Open Graph image, schema.org JSON-LD.
- Contact form posting to Web3Forms, with a `mailto:` fallback until an access key is configured.
- `README.md`, this changelog, `CREDITS.md`, `records/` (facts register, handoff, decisions) and `docs/website-repo-guide.md`.

### Changed
- All copy rewritten in plain sentences with concrete nouns. Capabilities now list named deliverables; past work is written as three case notes; a "How we work" section states scope limits.

### Removed
- Template files `elements.html`, `generic.html`, `README.txt`, `LICENSE.txt`, `assets/sass/`, jQuery and plugins, Font Awesome and its webfonts, and eight stock photographs (about 8 MB). With the last template file gone, the "Design: HTML5 UP" footer credit is removed in the same commit.

### Claims
- Corrected "full IL4 / LDAP / SSL compliance" to describe an IL4-accredited AWS GovCloud environment with LDAP integration and TLS. Source: the earlier site's own description plus a technical reading of the terms.
- Past work is presented as work led by the principals, some of it before the firm was formed. Google and NVIDIA are named as engineering teams worked alongside, not as partners.
- UEI, CAGE and NAICS codes are shown as "On request" until confirmed against SAM.gov.
