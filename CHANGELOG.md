# Changelog

Notable changes to manifold-llc.com. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). This site does not use Semantic Versioning; launches are tagged by date (for example `launch-2026-11`).

## [Unreleased]

### Added
- Hand-built single content page replacing the HTML5 UP "Solid State" template: `index.html`, `assets/css/site.css`, `assets/js/site.js`.
- Self-hosted fonts: Newsreader, IBM Plex Sans, IBM Plex Mono (SIL Open Font License), with license files in `assets/fonts/`.
- Wireframe manifold drawing generated by `scripts/surface.py`, used for the hero, logo mark, favicon and share image.
- Print-styled capability statement (`capability-statement.html` with `assets/css/capability-statement.css`) and its one-page, tagged PDF.
- `404.html`, `robots.txt`, `sitemap.xml`, `.well-known/security.txt`, favicon set, Open Graph image, schema.org JSON-LD, a meta Content-Security-Policy on every page.
- Contact form posting to Web3Forms once a key is configured, with a `mailto:` fallback and per-field error messages.
- `_config.yml` so GitHub Pages serves `.well-known` and does not publish `records/`, `docs/`, `scripts/` or the Markdown files.
- `.github/workflows/checks.yml`: HTML validation, link check, banned-pattern grep, facts grep, security.txt expiry and PDF page-count checks on every pull request. Dependabot keeps the pinned actions current.
- `README.md`, this changelog, `CREDITS.md`, `records/` (facts register, handoff, decisions) and `docs/website-repo-guide.md`.
