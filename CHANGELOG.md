# Changelog

Notable changes to manifold-llc.com. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). This site does not use Semantic Versioning; launches are tagged by date (for example `launch-2026-11`).

## [Unreleased]

### Added
- Hand-built single content page replacing the HTML5 UP "Solid State" template: `index.html`, `assets/css/site.css`, `assets/js/site.js`.
- Self-hosted fonts: Newsreader, IBM Plex Sans, IBM Plex Mono (SIL Open Font License), with license files in `assets/fonts/`.
- Wireframe manifold drawing generated by `scripts/surface.py`, used for the hero, logo mark, favicon and share image.
- Print-styled capability statement (`capability-statement.html` with `assets/css/capability-statement.css`) and its one-page, tagged PDF.
- `404.html`, `robots.txt`, `sitemap.xml`, `.well-known/security.txt`, favicon set, Open Graph image, schema.org JSON-LD, a meta Content-Security-Policy on every page.
- Contact form posting to Web3Forms once a key is configured, with a `mailto:` fallback and per-field error messages.
- `_config.yml` so GitHub Pages serves `.well-known` and does not publish `records/`, `docs/`, `scripts/` or the Markdown files.
- `.github/workflows/checks.yml`: HTML validation, link check, banned-pattern grep, facts grep, security.txt expiry and PDF page-count checks on every pull request. Dependabot keeps the pinned actions current.
- `README.md`, this changelog, `CREDITS.md`, `records/` (facts register, handoff, decisions) and `docs/website-repo-guide.md`.

### Changed
- All copy rewritten in plain sentences with concrete nouns. Capabilities list named deliverables; past work is written as three case notes attributed to the principals; a "How we work" section states scope limits.
- Cloud names corrected: AWS GovCloud, Azure Government, and Google Cloud's assured regions (the earlier draft said "Google GovCloud").
- Clearance wording: principals hold TS/SCI; classified discussion happens only under a sponsoring contract in the sponsor's spaces. Clearance moved out of the first hero fact.
- Contact copy asks visitors to keep Controlled Unclassified Information and procurement-sensitive detail out of the form, and names the form service.

### Removed
- Template files `elements.html`, `generic.html`, `README.txt`, `LICENSE.txt`, `assets/sass/`, jQuery and plugins, Font Awesome and its webfonts, and nine stock photographs (about 8 MB). With the last template file gone, the "Design: HTML5 UP" footer credit is removed in the same commit.
- "UEI / CAGE: On request" rows. Unconfirmed company data is not shown.

### Fixed
- Horizontal overflow at phone widths below 390 px.
- Small-text contrast: the label grey now measures at least 4.8:1 on every background; form-field borders meet the 3:1 non-text minimum.
- The form no longer posts anywhere when JavaScript is off.
- Sticky header has a solid fallback where `color-mix()` is unsupported.

### Claims
- Corrected "full IL4 / LDAP / SSL compliance" to describe an IL4-accredited AWS GovCloud environment with LDAP integration and TLS.
- Past work is presented as work led by the principals, some of it before the firm was formed. Google and NVIDIA are named once as vendor engineering teams worked alongside, not as partners.
- "The government side" was removed from the acquisition experience; the source does not establish whether the principals served as government staff or support contractors.
