# manifold-llc.com

Source for the Manifold LLC website, served by GitHub Pages at <https://manifold-llc.com>.

The site is one hand-written HTML page with one stylesheet and one small script. There is no build step, no framework, no third-party scripts, and no analytics. Fonts are self-hosted.

## Files

| Path | What it is |
|---|---|
| `index.html` | The site. All copy lives here. |
| `capability-statement.html` | Print-styled one-pager. `manifold-capability-statement.pdf` is rendered from it. |
| `404.html` | Not-found page (GitHub Pages serves it automatically). |
| `assets/css/site.css` | All styles. Design tokens are at the top. |
| `assets/js/site.js` | Footer year and the contact form handler. |
| `assets/fonts/` | Newsreader (display), IBM Plex Sans (text), IBM Plex Mono (labels). All SIL Open Font License. |
| `assets/img/manifold-surface.svg` | The hero drawing, generated by `scripts/surface.py`. |
| `favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, `assets/img/og.png` | Icons and the social-share image. |
| `CNAME` | Custom domain for GitHub Pages. Do not delete. |
| `robots.txt`, `sitemap.xml`, `.well-known/security.txt` | Crawler and security-contact files. |

## Editing copy

Edit `index.html` directly. Sections are marked with comments (`<!-- 01 Capabilities -->` and so on). Keep the house style: plain sentences, concrete nouns, no em-dashes, sentence-case headings. If a sentence could appear on any consultancy's site, replace it with a fact only Manifold can state.

When you change company facts (clearances, location, phone, email), change them in four places: the hero facts strip, the Company data table, the Contact aside, and `capability-statement.html`. Then re-render the PDF (below).

## Contact form

The form posts to [Web3Forms](https://web3forms.com) (free tier: 250 submissions a month, no account required, built-in spam filtering). Until a key is configured the form falls back to opening the visitor's mail client with the message pre-filled.

To turn on real delivery:

1. Go to web3forms.com, enter `info@teammanifold.com`, and confirm the email it sends you. It contains an access key.
2. In `index.html`, replace `REPLACE_WITH_WEB3FORMS_ACCESS_KEY` in the `data-access-key` attribute of the form with that key. The key is meant to be public.
3. Optionally, in the Web3Forms dashboard, turn on hCaptcha and restrict the key to the `manifold-llc.com` domain.

If you prefer Formspree, change the form's `action` to your Formspree endpoint and remove the `data-access-key` attribute; the script will then send a plain POST.

## Re-rendering the PDF, icons, and share image

These need Node and Playwright (`npm i -g playwright && npx playwright install chromium`), then from the repo root:

```bash
python3 -m http.server 8000 &
npx playwright pdf --format Letter "http://localhost:8000/capability-statement.html" manifold-capability-statement.pdf
npx playwright screenshot --viewport-size=1200,630 "http://localhost:8000/scripts/og.html" assets/img/og.png
npx playwright screenshot --viewport-size=180,180 "http://localhost:8000/scripts/icon.html" apple-touch-icon.png
```

The hero drawing can be regenerated with `python3 scripts/surface.py hero > assets/img/manifold-surface.svg`.

## Facts still to fill in

The following are marked "On request" on the site and in the PDF. Replace them once they are confirmed in SAM.gov, and keep the wording identical to the SAM record:

- UEI and CAGE code
- NAICS codes (typical for this work: 541511, 541512, 541690, 541715)
- Any socioeconomic status (SDVOSB, VOSB, 8(a), WOSB, HUBZone)
- Contract vehicles, SBIR Phase III eligibility, or marketplace listings
- Principal names, prior roles, and short bios (the strongest credibility signal a firm this size has)
- Facility clearance posture, if any

## DNS and HTTPS

GitHub Pages serves the site from the default branch. For the apex domain, DNS needs A records for `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, and `185.199.111.153` (optionally AAAA records too), and `www` should be a CNAME to `manifold-llc.github.io`. Once the DNS check passes in Settings, Pages, turn on "Enforce HTTPS".
