# manifold-llc.com

Source for the Manifold LLC website, served by GitHub Pages at <https://manifold-llc.com>.

The site is one hand-written content page, a 404 page and a print-styled capability statement, with one stylesheet and one small script. There is no build step, no framework and no third-party scripts on page load. Fonts are self-hosted.

## Editing copy

Edit `index.html` directly. Sections are marked with comments (`<!-- 01 Capabilities -->` and so on). Keep the house style: plain sentences, concrete nouns, no em-dashes, sentence-case headings. If a sentence could appear on any consultancy's site, replace it with a fact only Manifold can state.

When you change company facts (clearances, location, email), start in `records/facts.md`, which lists every place each fact appears (hero facts strip, Company data table, Contact aside, footer, JSON-LD, `capability-statement.html`, `404.html`, `.well-known/security.txt`, `assets/js/site.js`). Then re-render the PDF (below).

## Contact form

The form posts to [Web3Forms](https://web3forms.com) (free plan: 250 submissions a month, spam filtering included). The account is info@manifold-llc.com and the form is named "manifold-llc.com contact"; its public access key sits in the `data-access-key` attribute of the form in `index.html`. Submissions are emailed to the account address. The `action` stays `#contact` so that visitors without JavaScript see a mail link instead of sending data anywhere.

To rotate the key, create a new form in the Web3Forms dashboard (app.web3forms.com) and replace the attribute value. Optional hardening in the dashboard: turn on hCaptcha and restrict the key to the `manifold-llc.com` domain.

If you prefer Formspree, change the form's `action` to your Formspree endpoint and remove the `data-access-key` attribute; the script will then send a plain POST.

## Re-rendering the PDF, icons, and share image

These need Node and Playwright (`npm i -g playwright@1.65 && npx playwright install chromium`), then from the repo root:

```bash
python3 -m http.server 8000 &
node scripts/render.js
```

`scripts/render.js` renders the PDF (US Letter, tagged for accessibility, two pages), the share image and the touch icon, and fails if the PDF is not exactly two pages.

The hero drawing can be regenerated with `python3 scripts/surface.py hero > assets/img/manifold-surface.svg`.

## Facts still to fill in

The following are not shown on the site or in the PDF until confirmed. Add them once they match the SAM.gov record word for word (the full list with sources is in `records/facts.md`):

- UEI and CAGE code
- NAICS codes, exactly as registered
- Any socioeconomic status (SDVOSB, VOSB, 8(a), WOSB, HUBZone)
- Contract vehicles, SBIR Phase III eligibility, or marketplace listings
- Principal names, prior roles, and short bios (the strongest credibility signal a firm this size has)
- Facility clearance posture, if any

## DNS and HTTPS

GitHub Pages serves the site from the default branch. For the apex domain, DNS needs A records for `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, and `185.199.111.153` (optionally AAAA records too), and `www` should be a CNAME to `manifold-llc.github.io`. Once the DNS check passes in Settings, Pages, turn on "Enforce HTTPS".
